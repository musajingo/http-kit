Injects a `fields: Option<Projection<ResponseField>>` field onto a struct.

## Arguments

| Argument | Description |
|---|---|
| `ResponseField` | The `*Field` enum generated by `#[derive(ProjectionField)]` |
| `skip(validate)` | Omit `#[validate(nested, required(...))]` on the injected field |

## Example

```ignore
#[http_kit_macros::projection(ArticleField)]
#[derive(Debug, serde::Deserialize, validator::Validate)]
pub struct ListArticlesQuery {
    pub search: Option<String>,
    // Injected: fields: Option<Projection<ArticleField>>
}
```
